The MindClade Python SDK gives you a clean, Pythonic interface to the full MindClade API. It ships with comprehensive type hints, supports both synchronous and `async/await` usage patterns, and automatically retries requests that fail due to rate limits or transient server errors. Whether you are writing a quick script, a Django web app, or an async FastAPI service, the SDK fits naturally into your workflow.

<Note>
  The MindClade Python SDK requires **Python 3.8 or later**. It has no mandatory third-party dependencies beyond the standard library and `httpx`.
</Note>

## Installation

<CodeGroup>
```bash pip
pip install mindclade
```

```bash Poetry
poetry add mindclade
```
</CodeGroup>

## Initialization

Import `MindClade` and create a client. Pass your API key via an environment variable — never embed keys directly in source code.

```python
import os
from mindclade import MindClade

client = MindClade(
    api_key=os.environ["MINDCLADE_API_KEY"],
    environment="production",  # "sandbox" | "production" — defaults to "production"
)
```

<Tip>
  Set `environment="sandbox"` during local development and CI. Sandbox requests go to `https://sandbox.api.mindclade.com/v1` and are rate-limited to 100 req/min, leaving your production quota intact.
</Tip>

## Resources API

The Resources API lets you create, read, update, and delete the core objects in your MindClade account.

### List resources

Retrieve a paginated list of resources. Pass `limit` (up to 100) and an optional `cursor` from the previous response to continue paging.

```python
page = client.resources.list(limit=25)

print(page.data)        # list[Resource]
print(page.has_more)    # bool
print(page.next_cursor) # str | None

# Page through all resources
cursor = page.next_cursor
while cursor:
    next_page = client.resources.list(limit=25, cursor=cursor)
    cursor = next_page.next_cursor if next_page.has_more else None
```

### Create a resource

```python
resource = client.resources.create(
    name="Nightly ETL Pipeline",
    metadata={
        "owner": "data-team",
        "env": "production",
    },
)

print(resource.id)    # e.g. "res_01hx9k2mz4vbq8fpj3n7csdw"
print(resource.name)  # "Nightly ETL Pipeline"
```

### Get a resource by ID

```python
resource = client.resources.get("res_01hx9k2mz4vbq8fpj3n7csdw")

print(resource.id)        # "res_01hx9k2mz4vbq8fpj3n7csdw"
print(resource.metadata)  # {"owner": "data-team", "env": "production"}
```

### Update a resource

`update` performs a partial update — supply only the fields you want to change.

```python
updated = client.resources.update(
    "res_01hx9k2mz4vbq8fpj3n7csdw",
    name="Nightly ETL Pipeline — v2",
    metadata={
        "owner": "data-team",
        "env": "production",
        "version": "2",
    },
)

print(updated.name)  # "Nightly ETL Pipeline — v2"
```

### Delete a resource

```python
client.resources.delete("res_01hx9k2mz4vbq8fpj3n7csdw")
# Returns None on success; raises MindCladeError on failure
```

<Warning>
  Deletion is permanent. MindClade does not soft-delete resources — once you call `delete`, the resource and all associated data are removed immediately and cannot be recovered.
</Warning>

## Async Support

For async frameworks such as FastAPI, Starlette, or `asyncio`-based scripts, use `AsyncMindClade`. Its interface mirrors the synchronous client exactly — just `await` every call.

```python
import os
import asyncio
from mindclade import AsyncMindClade

async def main():
    async_client = AsyncMindClade(
        api_key=os.environ["MINDCLADE_API_KEY"],
        environment="production",
    )

    # Create a resource
    resource = await async_client.resources.create(
        name="Async Pipeline",
        metadata={"team": "platform"},
    )
    print(resource.id)

    # List resources
    page = await async_client.resources.list(limit=10)
    for r in page.data:
        print(r.id, r.name)

    # Delete it
    await async_client.resources.delete(resource.id)

asyncio.run(main())
```

<Tip>
  In FastAPI, declare the `AsyncMindClade` client at module level and reuse it across requests. Creating a new client per request adds unnecessary overhead.
</Tip>

## Events and Webhooks

### List events

```python
events = client.events.list(limit=50)

for event in events.data:
    print(f"{event.type} — {event.created_at}")
    # e.g. "resource.created — 2024-11-03T14:22:01Z"
```

### Register a webhook

```python
webhook = client.webhooks.create(
    url="https://hooks.yourapp.com/mindclade",
    events=["resource.created", "resource.updated", "resource.deleted", "event.triggered"],
)

print(webhook.id)      # e.g. "wh_02jy7p3nq5xcr9gtk4m0fave"
print(webhook.secret)  # store this — used to verify HMAC-SHA256 signatures
```

<Note>
  Save `webhook.secret` securely. MindClade only returns it once at creation time. You need it to verify the `X-MindClade-Signature` header on every incoming webhook request.
</Note>

### Verify a webhook signature

```python
from mindclade import verify_webhook_signature

is_valid = verify_webhook_signature(
    payload=request.body,   # raw bytes
    signature=request.headers["X-MindClade-Signature"],
    secret=os.environ["WEBHOOK_SECRET"],
)

if not is_valid:
    raise ValueError("Invalid webhook signature")
```

### Remove a webhook

```python
client.webhooks.delete("wh_02jy7p3nq5xcr9gtk4m0fave")
```

## Configuration

All parameters are accepted by both `MindClade` and `AsyncMindClade`. Only `api_key` is required.

| Parameter     | Type                        | Default        | Description                                                                                       |
|---------------|-----------------------------|----------------|---------------------------------------------------------------------------------------------------|
| `api_key`     | `str`                       | —              | **Required.** Your MindClade API key. Use `mk_live_…` for production, `mk_test_…` for sandbox.    |
| `environment` | `str`                       | `"production"` | Target API environment (`"sandbox"` or `"production"`). Controls the base URL automatically.     |
| `timeout`     | `float`                     | `30.0`         | Per-request timeout in seconds. Requests that exceed this limit raise `MindCladeTimeoutError`.    |
| `max_retries` | `int`                       | `2`            | Maximum automatic retries for 429 and 500 responses. Set to `0` to disable retry behaviour.      |
