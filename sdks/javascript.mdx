The MindClade JavaScript SDK gives you a fully typed, promise-based interface to every MindClade API endpoint. It runs in Node.js 16+ and modern browsers, ships with bundled TypeScript declarations, and automatically retries requests that fail due to rate limits or transient server errors — all with zero extra configuration.

## Installation

Add `@mindclade/sdk` to your project using your preferred package manager:

<CodeGroup>
```bash npm
npm install @mindclade/sdk
```

```bash yarn
yarn add @mindclade/sdk
```

```bash pnpm
pnpm add @mindclade/sdk
```
</CodeGroup>

## Initialization

Import the `MindClade` class and create a client instance. Pass your API key and, optionally, the target environment. Store your key in an environment variable — never hard-code it in source files.

```ts
import { MindClade } from '@mindclade/sdk';

const client = new MindClade({
  apiKey: process.env.MINDCLADE_API_KEY,
  environment: 'production', // 'sandbox' | 'production' — defaults to 'production'
});
```

<Tip>
  Use `environment: 'sandbox'` during development and CI. Sandbox requests hit `https://sandbox.api.mindclade.com/v1` and are rate-limited to 100 req/min, keeping your production quota untouched.
</Tip>

## Resources API

The Resources API lets you create, read, update, and delete the core objects in your MindClade account.

### List resources

Retrieve a paginated list of all resources. Pass `limit` (up to 100) and an optional `cursor` from the previous response to page through results.

```ts
const page = await client.resources.list({ limit: 25 });

console.log(page.data);        // Resource[]
console.log(page.has_more);    // boolean
console.log(page.next_cursor); // string | null

// Fetch the next page
if (page.has_more) {
  const nextPage = await client.resources.list({
    limit: 25,
    cursor: page.next_cursor,
  });
}
```

### Create a resource

```ts
const resource = await client.resources.create({
  name: 'Nightly ETL Pipeline',
  metadata: {
    owner: 'data-team',
    env: 'production',
  },
});

console.log(resource.id);   // e.g. "res_01hx9k2mz4vbq8fpj3n7csdw"
console.log(resource.name); // "Nightly ETL Pipeline"
```

### Get a resource by ID

```ts
const resource = await client.resources.get('res_01hx9k2mz4vbq8fpj3n7csdw');

console.log(resource.id);        // "res_01hx9k2mz4vbq8fpj3n7csdw"
console.log(resource.metadata);  // { owner: 'data-team', env: 'production' }
```

### Update a resource

`update` performs a partial update — only the fields you provide are changed.

```ts
const updated = await client.resources.update('res_01hx9k2mz4vbq8fpj3n7csdw', {
  name: 'Nightly ETL Pipeline — v2',
  metadata: {
    owner: 'data-team',
    env: 'production',
    version: '2',
  },
});

console.log(updated.name); // "Nightly ETL Pipeline — v2"
```

### Delete a resource

```ts
await client.resources.delete('res_01hx9k2mz4vbq8fpj3n7csdw');
// Resolves with void on success; throws MindCladeError on failure
```

<Warning>
  Deletion is permanent. MindClade does not soft-delete resources — once you call `delete`, the resource and all associated data are removed immediately.
</Warning>

## Events API

Fetch the event log for your account. Events record every significant action such as resource creation, updates, and webhook deliveries.

```ts
const events = await client.events.list({ limit: 50 });

for (const event of events.data) {
  console.log(`${event.type} — ${event.created_at}`);
  // e.g. "resource.created — 2024-11-03T14:22:01Z"
}

// Page through all events
let cursor = events.next_cursor;
while (cursor) {
  const next = await client.events.list({ limit: 50, cursor });
  cursor = next.has_more ? next.next_cursor : null;
}
```

## Webhooks API

Register a URL to receive real-time webhook notifications, and remove registrations you no longer need.

### Register a webhook

```ts
const webhook = await client.webhooks.create({
  url: 'https://hooks.yourapp.com/mindclade',
  events: ['resource.created', 'resource.updated', 'resource.deleted', 'event.triggered'],
});

console.log(webhook.id);     // e.g. "wh_02jy7p3nq5xcr9gtk4m0fave"
console.log(webhook.secret); // store this — used to verify HMAC-SHA256 signatures
```

<Note>
  Save `webhook.secret` securely. MindClade only returns it once at creation time. You will need it to verify the `X-MindClade-Signature` header on every incoming request.
</Note>

### Remove a webhook

```ts
await client.webhooks.delete('wh_02jy7p3nq5xcr9gtk4m0fave');
```

### Verify a webhook signature

```ts
import { verifyWebhookSignature } from '@mindclade/sdk';

// In your Express/Fastify/etc. handler:
const isValid = verifyWebhookSignature({
  payload: req.rawBody,           // raw Buffer or string
  signature: req.headers['x-mindclade-signature'],
  secret: process.env.WEBHOOK_SECRET,
});

if (!isValid) {
  return res.status(401).send('Invalid signature');
}
```

## TypeScript Types

The SDK exports every type you need for end-to-end type safety. Import them directly from the package root:

```ts
import type {
  Resource,
  Event,
  Webhook,
  ListResponse,
  MindCladeError,
} from '@mindclade/sdk';

// Generic list type — works for all paginated endpoints
type ResourcePage = ListResponse<Resource>;

function handleResource(resource: Resource): void {
  console.log(resource.id, resource.name, resource.metadata);
}
```

## Configuration Options

All options are passed to the `MindClade` constructor. Only `apiKey` is required.

| Option        | Type                          | Default        | Description                                                                                  |
|---------------|-------------------------------|----------------|----------------------------------------------------------------------------------------------|
| `apiKey`      | `string`                      | —              | **Required.** Your MindClade API key. Use `mk_live_…` for production, `mk_test_…` for sandbox. |
| `environment` | `'production' \| 'sandbox'`   | `'production'` | Target API environment. Sandbox requests go to `https://sandbox.api.mindclade.com/v1`.       |
| `timeout`     | `number`                      | `30000`        | Per-request timeout in milliseconds. Requests that exceed this limit throw a `TimeoutError`. |
| `maxRetries`  | `number`                      | `2`            | Maximum number of automatic retries for 429 and 500 responses. Set to `0` to disable.       |
