## Global Constraints

- Preserve Bazel 9.1.1, Rust 1.96.1, TypeSpec compiler/HTTP 1.16.0, Node 22.23.2, pnpm 12.3.4, Python 3.12.14, and the committed Nix lock baseline.
- Nix supplies tools; Bazel owns product compilation and tests. No downloads or package installation within build/test actions.
- Architecture YAML remains authoritative. Planned JSON architecture placeholders remain inactive.
- Update SemanticInput@v1 and MindcladeGraph@v1 in place, as explicitly directed by the user on 2026-09-23. Do not introduce parallel v2 APIs or schemas.
- Generated clients must not depend on internal execution contracts. RuntimeKit contains lifecycle/transport infrastructure, not domain execution policy.
- Keep service semantics modular-monolith-first until deployment evidence justifies a split.
- Public limit: 64 KiB transport body, 4096 Unicode scalar values per message, 128 tags with 64 scalar values per tag, requestId using the kernel component grammar.
- Source proposals and generated fixtures are not independent acceptance. Preserve original compatibility failures until a contract owner explicitly accepts the proposed baseline.

## Review Focus

1. Invalid dates/UTF-8/surrogates, duplicate object keys, unsafe numeric representations and generation exhaustion fail before storage/transport conversion: B1a/B2a.
2. Public TS/OpenAPI/Proto/MCP/docs must exclude internal types transitively and agree with independent expectations, not merely with each other: B2a/B2b.
3. Descriptor duplicate keys/aliases/tags/unknown sections, embedded secret values and unresolved references cannot reach RuntimeKit: B3a.
4. Slow/incomplete bodies, spoofed identity, oversized input, disconnect and shutdown cannot bypass bounds or leave unowned processes: B3b.
5. Missing configurations, unresolved imports, test-to-production leakage, cycles and forged dependency facts never pass from directory inventory: B4.
