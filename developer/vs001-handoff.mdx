### Running the non-durable Echo binary (B3b)

Build it with `nix develop --no-write-lock-file -c bazel build //services/foundation_echo:foundation_echo`, then run the file that `bazel cquery --output=files //services/foundation_echo:foundation_echo` names. It serves the generated loopback configuration through the test admission port, so nothing is durable (`"admission":"test"`).

- **stdin is the supervisor control channel.** A `shutdown` line _or end of input_ requests a drained shutdown. Run it with stdin open, for example in a terminal. With `</dev/null`, `nohup … &` or any closed stdin, it prints the ready receipt, drains at once and exits 0.
- **stdout** carries exactly two receipts, `FoundationEchoReady@v1` (with the bound address) and `FoundationEchoStopped@v1`. **stderr** carries telemetry only.
- **Exit codes:** 0 drained, 3 configuration, 4 bind or identity, 5 overrun, 1 other (B3b criteria section 3.6).
