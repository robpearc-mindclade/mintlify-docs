## Startup prompt

Use this in a fresh Claude context:

> Resume this private Mindclade vNEXT repository using CLAUDE.md, AGENTS.md, start-here and agent-handoff. Read the canonical task register and tracked foundation-development workflow. Resume from the register's next task using its frozen criteria: docs/superpowers/specs/README.md indexes those on main, and the register names any still on claude/\* branches. Recheck actual progress and my assigned scope; this startup prompt alone grants no execution. Have the current integration owner supply fresh checkout/common-Git-directory, branch/base/candidate/remotes, dirty paths/worktrees/locks, Linear/path ownership, attempts/jobs/receipts, exact reviewed specification/criteria, accepted inputs, scope, budget and permitted tools. Reconcile interrupted work before dispatch. Identify my role and owned/excluded paths. Follow fresh criteria, implementation, task review and whole-candidate review separation. When parent execution applies, do not run checks/builds/jobs/Git/remotes or delegate; return scoped edits and a report with evidence limits. Preserve concurrent work and immutable old receipts. Report missing authority/tools to the owner without inventing access. Keep source completion separate from admission, runtime and independent qualification.

The prompt carries no task status on purpose; the [current task register](/developer/agent-handoff#current-task-register) owns it.
