Whether you're connecting your product to third-party services, automating workflows, or building new features on top of a reliable API, MindClade gives you the primitives — REST endpoints, first-class SDKs, real-time webhooks, and clear documentation — to move fast without breaking things. ## How it works

Getting from zero to a working integration takes three steps. Follow them in order the first time, then revisit individual sections as your needs grow.

<Steps>
  <Step title="Create your account and get an API key">
    Head to the [MindClade dashboard](https://app.mindclade.com) and sign up for a free account. Once you're in, navigate to **Settings → API Keys** and create your first key. You'll get a `mk_test_` key for the sandbox environment right away — no credit card required.
  </Step>
  <Step title="Make your first API call">
    Use the key to hit `GET /resources` on the sandbox base URL (`https://sandbox.api.mindclade.com/v1`). You can use curl, our JavaScript SDK (`@mindclade/sdk`), or our Python SDK (`mindclade`) — whichever fits your workflow. The [Quickstart](/quickstart) walks you through all three.
  </Step>
  <Step title="Set up webhooks">
    Register a webhook endpoint with `POST /webhooks` to start receiving real-time event notifications — `resource.created`, `resource.updated`, and more. Every payload is signed with HMAC-SHA256 so you can verify it came from MindClade. See the [Webhooks guide](/guides/webhooks) for a complete walkthrough.
  </Step>
</Steps>
