This document records the bootstrap finalization status as of 2026-09-28, with baseline from 2026-09-23 and statuses refreshed at the 2026-09-26 pre-migration closeout, remote governance on 2026-09-27, and the R2 CI-substrate reconciliation on 2026-09-28. Scope is the repository and architecture baseline, not completion of VS-001 or a production/scientific release. The [agent handoff](/developer/agent-handoff) is the current recovery entry point; historical checks are bound to their named revisions, not automatically attributed to later documentation or source.

## Finalized baseline

The following items constitute the accepted finalized baseline:

- Accepted ADR-000 through ADR-014 and their architecture laws are preserved.
- ADR-015 records alignment and the user's explicit original-blueprint scaffold exception.
- The master blueprint reconciles compiler, kernel, science, execution, assurance, agent, product and deployment responsibilities.
- The complete tree includes every original blueprint path and explicit stubs. Layout metadata separates bootstrap source from scaffolded, unimplemented roots.
- The Notion review retains source coverage, adoption decisions and limitations.
- Repository checks cover inventory drift, root activation, placeholder markers, malformed layout metadata and local Markdown file links.
- The executable foundation resolves the official TypeSpec Echo HTTP fixture, validates the kernel and immutable graph, and emits reproducible graph/manifest bytes through Rust Codegen. This is a limited compiler slice, not full VS-001.
- The immutable original attachment and manifest verify 706 directories, 124 named files and 38 nested extensions. The scaffold manifest owns the current stub inventory; package/lock placeholders, the supervised PR template, the documentation index, the four B4 `tools/validation` wrappers and the codegen, contracts, tools, tests and services READMEs have reviewed activation transitions. The preserved `contracts/typespec/main.tsp` is a comment-only tombstone that declares nothing and is explicitly excluded from compilation; see its [retirement record](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/docs/reviews/2026-09-26-k1-32-contracts-typespec-main-retired.md). Unrelated stubs remain sealed. Documentation activation does not activate a runtime component.

## Available local checks

Run these commands from the repository root:

```bash
nix develop --no-write-lock-file -c just verify
nix develop --no-write-lock-file -c just fmt-check
nix develop --no-write-lock-file -c just check   # fast subset: no Bazel
```

The aggregate separates fast source checks, scaffold integrity, inventory/link checks, real Nix/Bazel/Cargo build/tests, and read-only generated-output checks.

Clean Apple Silicon aggregate passed on reviewed B3a head `06d0e10` and [Linux main CI](https://github.com/robpearc-mindclade/mindclade-vnext/actions/runs/35955099688) passed for main checkpoint `06a903f8bb04c993d5a6282c07ae1a8fa25ad262`, whose tree is identical to that head. Generated-drift checks passed; cross-host artifact byte comparison was not refreshed for this checkpoint. Earlier checkpoints (`a0d6d41` and before) and their exact-parity results remain historical. New revisions require applicable fresh checks.

<Warning>
  Intel macOS has no development shell (H1-19). These remain source-level checks. The link checker validates local file targets and Markdown anchors, not remote URLs. Inventory validation does not prove semantic import layering.
</Warning>

The exact results belong to the final change handoff and subsequent CI receipts.
