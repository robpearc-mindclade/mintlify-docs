This page locates every section of the supplied greenfield blueprint and every architectural box in the layered reference image. It is for developers, reviewers, and agents checking design alignment.

<Warning>
  This is an explanatory traceability map, dated 2026-09-23. Coverage means a concept has an owned reference and repository responsibility. It does not mean the concept is implemented, qualified, or approved for operation. The [task register](/developer/agent-handoff#current-task-register) and [maturity model](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/docs/architecture/maturity.yaml) retain status authority.
</Warning>

## Source and interpretation

The immutable [original greenfield blueprint](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/docs/architecture/sources/original-greenfield-blueprint.md) is the exact supplied source, SHA256 `c23d824ea6d2890bde8d1032ce4e0341cbd98ea4cc217c94eb0cec36c7665c38`. Accepted ADRs reconcile its target picture without silently rewriting that source. [ADR-003](/architecture/adr/adr-003-mindcladegraph-and-typed-graph-views) makes SemanticGraph and CapabilityGraph typed views of one immutable MindcladeGraph; [ADR-015](/architecture/adr/adr-015-original-blueprint-scaffold-alignment) preserves the original roots through an explicit planned-scaffold exception.

The [layered diagram](/architecture/platform-diagram) and its text equivalent show the same design from a different viewpoint than the master's four cross-cutting responsibilities. The image is illustrative, not a Codegen-emitted atlas. Its earlier 38%/42%/20% annotations described layout widths, never implementation or qualification percentages; the cleaned illustration omits them.

## Maintaining coverage

When a component is activated, update its authoritative model/maturity, contracts, descriptor, ownership, and checks together with the relevant explanatory page. Retire manifest-listed stubs through the reviewed transition; do not reseal them or infer implementation from a file's presence. Refresh the mechanical inventory through its existing tool. Keep this map about coverage and leave revision-bound results and pending work in their existing records.

The corrected image shows the default TypeSpec-led path: Protobuf is generated. The [surface ownership ledger](/architecture/generated-surface-ownership) retains the original blueprint's optional Protobuf-first input only under disjoint reviewed ownership. Generated bindings do not make all SDK, MCP, Terraform, CDK, or UI code disposable output.
