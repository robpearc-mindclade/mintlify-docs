## Status

| Attribute | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-09-22 |

## Context

Without standardized platform primitives, services accumulate divergent lifecycle logic, configuration handling, and test infrastructure, making qualification and agent-assisted development harder.

## Decision

RuntimeKit and TestKit are platform primitives.

RuntimeKit standardizes service lifecycle, configuration, health, identity, middleware, telemetry, error handling, and shutdown. TestKit standardizes deterministic fixtures, fake clocks, fake workers, fake storage, fake events, fake models, and assertions.

- Services stay thin.
- Agents have a narrow path for adding service behavior.
- VS-001 uses a deterministic fake Clade worker for system proof, not scientific validation.
