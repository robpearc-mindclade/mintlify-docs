This page records ADR-000, the architecture constitution for Mindclade vNEXT. It is authoritative: architecture-law changes require explicit ADR review.

## Status

| Attribute | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-09-22 |

## Context

Before broad implementation begins, Mindclade vNEXT needs a frozen set of governing laws so that architecture changes are deliberate and reviewed.

## Decision

Mindclade vNEXT is governed by a small architecture constitution before broad implementation begins.

The constitution freezes the laws for stable truth, dynamic execution, Codegen, `MindcladeGraph`, typed references, evidence, claims, policy, decisions, independent assurance, modular deployment, generated projections, agent capability attenuation, and governed evolution.

## Consequences

- Architecture-law changes require explicit ADR review.
- Empty scaffolding is discouraged.
- VS-001 is the first proving ground.
