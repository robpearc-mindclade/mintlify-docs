This architecture decision record establishes that generated output is always a downstream projection, never an authoritative source. It is for engineers working with generated code, documentation, or infrastructure, and reviewers assessing whether a file may be hand-edited.

## Status

| Attribute | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-09-22 |
| Related | Not stated |

## Context

Generated files are often treated as editable source, leading to drift between contract and projection, and making regeneration dangerous or impossible.

## Decision

Generated output is a projection, not source authority.

Generated surfaces include Protobuf, OpenAPI, JSON Schema, SDKs, MCP, docs, Terraform, CDK, architecture views, and generated C ABI surfaces.

## Consequences

- Generated files are never edited manually.
- Generation must be reproducible and provenance-bound.
- Dirty regeneration blocks qualification.

## Alternatives

Not stated.
