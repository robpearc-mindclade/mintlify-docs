This architecture decision record establishes the engineering factory model for Mindclade. It is for architects, platform engineers, and anyone designing work units or agent scopes.

## Status

| Attribute | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-09-22 |
| Related | Not stated |

## Context

As the system evolves, an increasing share of implementation and maintenance can be performed by agents or factory processes. However, the factory must not gain the authority to redesign architecture without human review.

## Decision

Mindclade will develop toward an engineering factory, but the factory cannot redesign architecture autonomously.

Work units carry objectives, architecture nodes, owned paths, allowed dependencies, capabilities, acceptance criteria, tests, assurance profile, mutation ceiling, budget, and expected artifacts.

## Consequences

- Agents can increasingly implement and maintain source.
- Architecture-law changes require explicit review.
- Repository telemetry, incidents, evaluation results, and scientific evidence feed proposals, policies, tasks, evidence, and decisions.
