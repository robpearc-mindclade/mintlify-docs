## Deliberate reconciliation

Existing Rust implementations remain in core/src and codegen/src; the original module-directory reservations do not create duplicate libraries. Accepted ADRs remain canonical in docs/architecture/adr. The original docs/adr and architecture decisions directories are reserved stubs, not competing decision authorities.

The original descriptor example and .v1.json filenames describe future contracts, not already implemented schemas. Stub descriptors omit executable configuration and cannot authorize deployment. No example credentials, runtime entrypoints, cloud quotas, or health endpoints are asserted as working.

The original model names and multiple service names reserve possible destinations; they do not select checkpoints, force separate deployments, or override modular-monolith-first. Thin service subdirectories must stay adapters/orchestration, not duplicate domain frameworks.

The existing biological-source review, scientific requirements, independent assurance, exact-candidate evidence, effect reconciliation, budgets, and generated product checks remain part of vNEXT. Extensions preserve core Reference/Decision, BiologicalState context, knowledge citations/claims/linking, NOVA shared representation, experiment orchestration, engineering workflows, and release tests.
