This page records the 2026-09-26 historical decision to retire `contracts/typespec/main.tsp` to a tombstone. The retired content below is not a contract, a TypeSpec source, a Codegen input, or an authority. Nothing compiles, imports, or validates it.

## Scope and outcome

| Date | Scope | Outcome |
| --- | --- | --- |
| 2026-09-26 | Retire `contracts/typespec/main.tsp` to a comment-only tombstone per K1-32 Amendment 1 | File preserved as tombstone; pinned blueprint path retained |

## Disposition

- `contracts/typespec/main.tsp` stays, because the pinned original blueprint tree names it and the [scaffold manifest](../model/blueprint-scaffold.json) keeps it as a preserved file. Its content is now a comment-only [tombstone](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/main.tsp) that declares nothing, so compiling it, including through `tsp compile contracts/typespec`, yields an empty program.
- No `typespec_compile` target compiles the tombstone. The [contract-source manifest](../model/contract-sources.json) excludes it with this reason. [validate_contract_sources.py](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/scripts/validate_contract_sources.py) requires every `contracts/**/*.tsp` to be a declared compile source or an explicit exclusion. It also fails if an uncompiled default entrypoint beside a `tspconfig.yaml` is not excluded or declares anything.
- Original file: added by the bootstrap commit `f76ceae`; 1562 bytes, SHA-256 `1de4851a4182b7cebe31bb48a777ca9d89329e33fd65d63499b31361600ba7d6`, Git blob `8ed6645e7ac3b5a245ac0c50c2d28e3868dfbd8b`.

## Why the content was retired

- No `typespec_compile` target named it as an entrypoint, public source, or internal source. The official frontend never compiled it and Codegen never consumed it, yet its location under `contracts/` presented it as authored contract truth.
- It declared a separate `Mindclade.VNext` namespace whose models used free-form strings for identity components, digests, reference target kinds, and timestamps. These disagree with the validated kernel identities and references and with the VS-001 contracts.
- [tspconfig.yaml](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/tspconfig.yaml) configures the official emitter with the `mindclade/foundation/v1` package identity. Running `tsp compile contracts/typespec` compiles that directory's `main.tsp` by default, so the old content could have emitted a second, unrelated semantic input under the foundation package identity.

- Internal contracts: [internal/main.tsp](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/internal/main.tsp), [execution.tsp](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/internal/execution.tsp), and [assurance.tsp](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/internal/assurance.tsp).

- Kernel identity, reference, and record semantics: [core/src/lib.rs](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/core/src/lib.rs).
- Service descriptors: [ServiceDescriptor@v1](../service-descriptor-v1).
- The declared compile sources are the `typespec_compile` targets in [the frontend BUILD file](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/codegen/frontend/typespec/BUILD.bazel).

## Decisions

- `contracts/typespec/main.tsp` remains as a scaffold-preserved tombstone, not a compile source.
- The pinned blueprint path is retained per Rob's same-day amendment.
- `validate_contract_sources.py` enforces that every `.tsp` file is either a declared compile source or an explicit exclusion.

## Follow-ups

- Ensure no `typespec_compile` target inadvertently includes the tombstone.
- Monitor the contract-source manifest for future exclusions.

## Evidence

No JSON evidence files are produced. Evidence is the tombstone file content, Git blob hash, and SHA-256 digest as recorded above.
