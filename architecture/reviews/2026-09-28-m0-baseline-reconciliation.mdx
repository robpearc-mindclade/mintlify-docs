## Echo through the actual pipeline

[echo.tsp](https://github.com/Mindclade-org/mindclade-internal-monorepo/blob/main/contracts/typespec/public/echo.tsp) owns `POST /echo/{requestId}`, bounded request fields and 200/400/409/503 alternatives. The official frontend in `codegen/frontend/typespec/src/{cli,index,declarations}.mjs` resolves supported TypeSpec semantics once; the `:vs001_services` action stages declared descriptor files and records their path/digest/location inventory in `SemanticInputV1`. `codegen/src/pipeline.rs` exposes `Compiler::{compile,compile_with_architecture,compile_services}`; `compile_services` receives the descriptor bytes separately as `DescriptorSource` values and checks their duplicate-free inventory/digest correspondence before compiling and sealing the immutable graph in `graph.rs`. Semantic, capability, public, architecture and service views borrow that graph; none is another authority.

`codegen/src/target_ir.rs:149` implements the TargetBundleIR responsibility as `TargetBundle<'a>`, borrowing the sealed graph and carrying the transport profile. Emitters consume this checked lowering, not TypeSpec again. Descriptor, architecture model and current/previous Proto registries are authored inputs. `emit/`, `projection.rs` and `publication.rs` own the recoverable fourteen-file catalog: graph/manifest, TypeScript client, Rust modules, OpenAPI, messages-only Proto, MCP metadata, README, descriptor, checked config and HTTP adapter. MCP metadata is not a running MCP server; Proto is not a gRPC service.

The actual client API is `createEchoClient({ baseUrl, fetch? }).echo(requestId, body, { signal? })`, returning `Promise<EchoResponse>` (`generated/vs001/public/client.ts:327-339`). It validates before fetch, checks bounded responses, rejects redirects and distinguishes validation, API, protocol, transport and transport-rejection errors. Abort is a transport outcome, not durable cancellation. Consumer tests and the process harness exercise this client; installed-package consumer qualification is absent.

Echo includes generated DTO/config/HTTP modules; `composition.rs` binds an `AdmissionPort` to checked tenant, environment, identity and descriptor digest. The generated adapter validates route/method/media/body and maps typed errors. RuntimeKit receives a generic handler and owns bounded HTTP and lifecycle; it does not import Echo, Codegen or TestKit or parse the YAML descriptor. The current descriptor selects loopback, `admission: test`, optional PostgreSQL and disabled deployment. `TestAdmission` returns the checked message, writes nothing and never returns conflict. Readiness is `FoundationEchoReady@v1` with test admission; stdin shutdown/EOF drains through the bounded supervisor. A restart preserves no Run, artifact or outbox state.

Real-socket process tests, independent-expectation conformance, malformed-input negatives and TestKit-ordered races exist. B4's configured dependency collectors, compiler evaluator and four wrappers exist; W6 activated-source records and the DX2 verifier/fixtures also exist. These should be reused, while both actual DX2 rehearsal halves and connected engineering acceptance remain separate. The PostgreSQL probe proves only its fixed prerequisite workload: three clusters, owned lifecycle/recovery/cleanup and bounded observations. It exposes no reusable `PgHarness`, `PgStore`, migration, execution engine or fixture library.
