- Design sections 3/5/6: B1a and B2 products preserve in-place v1 and strict public/internal boundaries; B3 compiles descriptors and real non-durable composition; B4 owns actual configured dependency enforcement.
- Design durability and assurance sections: all C1-C5/D1-D4 tasks remain linked with predecessor and acceptance gates. Full VS-001 cannot close on TestAdmission.

- New contributor requirement: DX1/DX2 add tracked setup, owner/maturity lookup, independent human/agent exercises, failure diagnosis and interruption handoff.
- Parent checked interface names and dependency order, corrected YAML ordering, distinguished compiler descriptor from generated RuntimeKit config, removed an audit/binding exception import cycle, and aligned the developer test runner with the fixed command loop.
- Fresh whole-candidate review found and resolved the architecture-membership prerequisite, the DX2/O4 completion cycle and conflicting retained B RuntimeKit/PostgreSQL instructions. B3a owns membership parsing before B4 enforcement; DX2 commits local proof before O4; retained B/C/D/delivery execution headers now follow the current supervised roles.
- Parent checked every Review Focus condition against a named owning task and its required negative/positive cases. Proposed tests are not execution receipts. Schema/profile decisions requiring contract review remain explicit pre-implementation steps, not undocumented implementer choices.

## Definition of done

The planning package is ready for human review after repository inventory/link/scaffold and whitespace validation. It is not evidence that compiler/products, RuntimeKit, dependency enforcement, queue verification, fresh contributor rehearsal or operational acceptance are complete. SAML, private protection/queue entitlement, operator trust custody and tracker access remain external gates until freshly observed and accepted.

The next source units are DX1 and G1, with independent criteria review and non-overlapping ownership. No blanket approval for future source-only merges, policy adoption, repository transfer, paid entitlement or release publication is created by this plan.
