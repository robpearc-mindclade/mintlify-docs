The Resources API is the core of MindClade. Every object you create, configure, and manage on the platform is a resource — a named, metadata-enriched entity that your application reads, transforms, or acts on. Use the five endpoints below to build full lifecycle management into your integration: list what exists, create new entries, inspect individual records, update fields in place, and remove what you no longer need.

---

## List resources

`GET /resources`

Retrieve a paginated list of all resources in your account. Results are returned in reverse-chronological order (newest first) and can be filtered by metadata key-value pairs.

### Query parameters

<ParamField query="limit" type="integer" default="50">
  Maximum number of resources to return. Accepts values between `1` and `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor returned as `next_cursor` in the previous response. Omit to start from the beginning.
</ParamField>

<ParamField query="metadata[key]" type="string">
  Filter resources by a metadata field. Replace `key` with the metadata field name — for example, `metadata[env]=production`. You may include multiple `metadata[key]` parameters in a single request.
</ParamField>

### Request example

<CodeGroup>
```bash cURL
curl https://api.mindclade.com/v1/resources \
  -H "Authorization: Bearer mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" \
  -G \
  --data-urlencode "limit=25" \
  --data-urlencode "metadata[env]=production"
```

```javascript JavaScript
import MindClade from "@mindclade/sdk";

const client = new MindClade({ apiKey: "mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" });

const page = await client.resources.list({
  limit: 25,
  metadata: { env: "production" },
});

for (const resource of page.data) {
  console.log(resource.id, resource.name);
}
```

```python Python
import mindclade

client = mindclade.MindClade(api_key="mk_live_4xKz9mPqRtL2vNwY8cJdB3sH")

page = client.resources.list(
    limit=25,
    metadata={"env": "production"},
)

for resource in page.data:
    print(resource.id, resource.name)
```
</CodeGroup>

### Response example

```json

    {
      "id": "res_8fT3kWmXpQnL1vZa",
      "name": "Primary Pipeline",

    {
      "id": "res_2rN7bCsYdHjE9oKu",
      "name": "Analytics Sink",
      "status": "active",
      "metadata": { "env": "production", "team": "data" },

  "has_more": true

```

### Response fields

<ResponseField name="data" type="array">
  Array of Resource objects matching the query.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Cursor to pass as the `cursor` query parameter to retrieve the next page. `null` when no further pages exist.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` when additional pages are available beyond the current response.
</ResponseField>

## Create a resource

`POST /resources`

Create a new resource in your account. Supply a human-readable name and any metadata you want attached from the start. MindClade generates the resource ID and timestamps automatically.

### Body parameters

<ParamField body="name" type="string" required>
  Human-readable display name for the resource. Must be between 1 and 255 characters.
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary key-value pairs to attach to the resource. Keys and values must be strings. You may store up to 50 keys with values up to 500 characters each.
</ParamField>

### Request example

<CodeGroup>
```bash cURL
curl -X POST https://api.mindclade.com/v1/resources \
  -H "Authorization: Bearer mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ingestion Worker",
    "metadata": {
      "env": "production",
      "region": "us-east-1",
      "team": "platform"
    }
  }'
```

```javascript JavaScript
import MindClade from "@mindclade/sdk";

const client = new MindClade({ apiKey: "mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" });

const resource = await client.resources.create({
  name: "Ingestion Worker",
  metadata: {
    env: "production",
    region: "us-east-1",
    team: "platform",
  },
});

console.log(resource.id); // res_9gU4lXnYqRoM2wAb
```

```python Python
import mindclade

client = mindclade.MindClade(api_key="mk_live_4xKz9mPqRtL2vNwY8cJdB3sH")

resource = client.resources.create(
    name="Ingestion Worker",
    metadata={
        "env": "production",
        "region": "us-east-1",
        "team": "platform",
    },
)

print(resource.id)  # res_9gU4lXnYqRoM2wAb
```
</CodeGroup>

### Response example

```json
{
  "id": "res_9gU4lXnYqRoM2wAb",
  "name": "Ingestion Worker",
  "status": "active",
  "metadata": {
    "env": "production",
    "region": "us-east-1",
    "team": "platform"
  },
  "created_at": "2025-06-14T10:33:07Z",
  "updated_at": "2025-06-14T10:33:07Z"
}
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the resource, prefixed with `res_`. Use this ID in all subsequent operations on the resource.
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable name you supplied at creation.
</ResponseField>

<ResponseField name="status" type="string">
  Lifecycle status of the resource. One of `active` or `archived`.
</ResponseField>

<ResponseField name="metadata" type="object">
  The key-value metadata attached to the resource.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the resource was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp recording when the resource was last modified.
</ResponseField>

## Retrieve a resource

`GET /resources/{id}`

Fetch a single resource by its unique ID. Use this endpoint to confirm the current state of a resource before performing updates or to display resource details in your application.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the resource to retrieve, for example `res_9gU4lXnYqRoM2wAb`.
</ParamField>

### Request example

<CodeGroup>
```bash cURL
curl https://api.mindclade.com/v1/resources/res_9gU4lXnYqRoM2wAb \
  -H "Authorization: Bearer mk_live_4xKz9mPqRtL2vNwY8cJdB3sH"
```

```javascript JavaScript
import MindClade from "@mindclade/sdk";

const client = new MindClade({ apiKey: "mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" });

const resource = await client.resources.retrieve("res_9gU4lXnYqRoM2wAb");

console.log(resource.name);   // "Ingestion Worker"
console.log(resource.status); // "active"
```

```python Python
import mindclade

client = mindclade.MindClade(api_key="mk_live_4xKz9mPqRtL2vNwY8cJdB3sH")

resource = client.resources.retrieve("res_9gU4lXnYqRoM2wAb")

```

## Update a resource

`PATCH /resources/{id}`

Update the `name` or `metadata` of an existing resource. Metadata is **merged**, not replaced — keys you omit remain unchanged, and keys you include are added or overwritten. To remove a metadata key, set its value to `null`.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the resource to update, for example `res_9gU4lXnYqRoM2wAb`.
</ParamField>

### Body parameters

<ParamField body="name" type="string">
  New display name for the resource. Omit to leave the existing name unchanged.
</ParamField>

<ParamField body="metadata" type="object">
  Metadata fields to add or overwrite. Existing keys not included in this object are preserved. Set a key to `null` to remove it.
</ParamField>

### Request example

<CodeGroup>
```bash cURL
curl -X PATCH https://api.mindclade.com/v1/resources/res_9gU4lXnYqRoM2wAb \
  -H "Authorization: Bearer mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ingestion Worker — v2",
    "metadata": {
      "region": "eu-west-1",
      "version": "2.0.0"
    }
  }'
```

```javascript JavaScript
import MindClade from "@mindclade/sdk";

const client = new MindClade({ apiKey: "mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" });

const resource = await client.resources.update("res_9gU4lXnYqRoM2wAb", {
  name: "Ingestion Worker — v2",
  metadata: {
    region: "eu-west-1",
    version: "2.0.0",
  },
});

console.log(resource.name);              // "Ingestion Worker — v2"
console.log(resource.metadata.region);  // "eu-west-1"
console.log(resource.metadata.env);     // "production" — untouched
```

```python Python
import mindclade

client = mindclade.MindClade(api_key="mk_live_4xKz9mPqRtL2vNwY8cJdB3sH")

    name="Ingestion Worker — v2",

```
</CodeGroup>

## Delete a resource

`DELETE /resources/{id}`

Permanently delete a resource by ID. This action is irreversible — the resource and all associated metadata are removed from MindClade. Deleting a resource triggers a `resource.deleted` webhook event on all subscribed endpoints.

<Warning>
  Deletion is permanent and cannot be undone. Make sure you no longer need the resource — including any dependent pipelines or integrations — before proceeding.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the resource to delete, for example `res_9gU4lXnYqRoM2wAb`.
</ParamField>

### Request example

<CodeGroup>
```bash cURL
curl -X DELETE https://api.mindclade.com/v1/resources/res_9gU4lXnYqRoM2wAb \
  -H "Authorization: Bearer mk_live_4xKz9mPqRtL2vNwY8cJdB3sH"
```

```javascript JavaScript
import MindClade from "@mindclade/sdk";

const client = new MindClade({ apiKey: "mk_live_4xKz9mPqRtL2vNwY8cJdB3sH" });

const result = await client.resources.delete("res_9gU4lXnYqRoM2wAb");

console.log(result.deleted); // true
console.log(result.id);      // "res_9gU4lXnYqRoM2wAb"
```

```python Python
import mindclade

client = mindclade.MindClade(api_key="mk_live_4xKz9mPqRtL2vNwY8cJdB3sH")

result = client.resources.delete("res_9gU4lXnYqRoM2wAb")

print(result.deleted)  # True
print(result.id)       # "res_9gU4lXnYqRoM2wAb"
```
</CodeGroup>

### Response example

```json
{
  "deleted": true,
  "id": "res_9gU4lXnYqRoM2wAb"
}
```

### Response fields

<ResponseField name="deleted" type="boolean">
  Always `true` on a successful deletion.
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the resource that was deleted.
</ResponseField>
